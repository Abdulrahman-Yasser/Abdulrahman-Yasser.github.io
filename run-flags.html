Flags and Settings for the Surround View App

The command in step 8 has three parts: two variables that only tell the shell how to reach the screen, the BEV_* variables that configure the camera side (read by the Flutter app and by the native libbev_view.so), and the flags of the homescreen shell itself. For example, four cameras with a tighter zoom on the DRM backend: 

BEV_STAT=1 BEV_CAMERAS=4 BEV_PX_PER_M=120 ./homescreen -b . -f --backend drm-kms-egl

Environment variables:

VariableWhat it does
WAYLAND_DISPLAY=wayland-0The Wayland socket the shell connects to. Needed because the command runs over SSH, outside the desktop session
XDG_RUNTIME_DIR=/run/user/$(id -u)The folder that holds that socket. Also needed over SSH
BEV_STAT=1Shows the fps and buffer statistics on the views and prints a [stat] line to the console every half second
BEV_CAMERAS=2How many cameras the 360 view opens (default 2)
BEV_CONFIG=pathThe bev_config.ini with the camera poses and calibration (default bev_config.ini)
BEV_LENS_DIR=pathFolder with the lens distortion files, so the images are undistorted before the blend
BEV_PX_PER_M=nZoom of the bird's-eye canvas in pixels per meter. Higher shows a smaller area, and it overrides the value in the config file
BEV_CAM_FPS=30Frame rate the cameras are asked for by pinning the frame duration (default 30). Without a pin, auto exposure in low light dropped it to about 15
BEV_WIDTH, BEV_HEIGHTCapture size requested from the cameras. All cameras must end up with the same size
BEV_RENDER_NODE=/dev/dri/renderD128The GPU render node the buffers are allocated on. Only needed if the default pick is wrong
BEV_IMPLICIT_SYNC=1Submits frames without acquire fences. A fallback for ivi-homescreen builds older than v3.0 83887302, which leaked one sync file per frame

Shell flags (from homescreen --help):

FlagWhat it does
-b, --bundle pathThe Flutter bundle to run. . means the current folder (~/ui)
-f, --fullscreenStart fullscreen
--backend nameRendering backend: wayland-egl, wayland-vulkan, drm-kms-egl, drm-kms-vulkan or software. Defaults to wayland-egl inside a Wayland session, otherwise drm-kms-egl
-w, --width, --heightSize of the window in pixels
-p, --pixel-ratio nDevice pixel ratio, to scale the UI
-o, --output-index nWhich display to put the view on
-c, --disable-cursorHide the mouse pointer
-d, --debug-backendTurn on backend debug logging
--shell nameWayland shell protocol: auto, xdg, agl, ivi or simple
--engine-arg, --dart-argPass a switch to the Flutter engine, or an argument to the Dart main() (can be repeated)
-h, --helpPrint all options
